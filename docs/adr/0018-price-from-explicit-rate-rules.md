# 用显式条件规则调整价格

模型的一份完整 Price Policy 包含基础价格、扩展倍率与有限的条件规则。服务档位、速度、长上下文和日历分为四组；服务档位与速度只按自身取值匹配，长上下文按长度和可选适用速度匹配，重叠取值／区间禁止保存；只有时间组按显式优先级取首个匹配。组间按计量项相乘。统一倍率是规则内默认值，输入／输出和计量项独立倍率逐层覆盖，不能把统一倍率再乘一次。

选择有限条件匹配而非自由表达式，是因为已知需求需要组合条件和缓存独立调整，但不需要让管理员重写用量定义与整笔费用公式。协议字段和用量关系由适配器解释；共享层只处理可信事实、价格依赖和结算。Speed 独立于 ServiceTier，客户端请求值不能替代实际执行证据。

同一次计费使用一份当前完整价格发布，模型名称不提供隐藏倍率。Original Model Billing 选择原模型的完整策略；其他路径按既有实际模型规则选择策略，不能混用基础价和规则。操作开始时间固定，价格版本仍按 ADR-0034 在各使用阶段读取。

缺失或冲突的规则依赖不能被当作不匹配跳过；只在可证明倍率相同时继续计价，否则交给现有 Price Component 的缺证据处理。规则不授予新的 provider submission、换渠道或重试权限。原始协议的未知字段继续透传，未知但有效的实际枚举值按显式规则及兜底处理并记录诊断。

持久化继续使用 Price 的 rate_rules JSON。旧固定三规则未上线，直接替换，无迁移和双求值器；省略字段保留已有配置，显式空对象清空规则。规则不保存名称，界面用条件摘要展示；时区属于时间组。具体 schema、作用范围、证据要求和测试边界见 [条件倍率规则设计](../dev/pricing-rate-rules.md)。

本决策取代 ADR-0001 和 ADR-0004；不改变 ADR-0033 的原子组件结算或 ADR-0034 的配置读取时机。
