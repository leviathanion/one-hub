# Bound initial tool support by resource lifecycle

The initial GPT-5.6 surface fully supports Resource-Independent Tools when the selected channel can represent them, including function/custom tools, Programmatic Tool Calling, multi-agent, Web Search, Image Generation, local shell, and applicable client- or externally executed tools. Their wire events and independent billing evidence remain part of the supported contract. Tools that require an Account-Scoped Tool Resource, including File Search, hosted containers used by Shell or Code Interpreter, and uploaded Skill references, fail before provider work until the proxy supplies that resource's complete lifecycle, user ownership, and exact-channel routing. This semantic boundary preserves useful tool breadth without contradicting the decision that Stored Response is the only initially owned resource.

Hosted-tool base prices come only from the System Tool Price Catalog and final user charging additionally applies the existing group ratio. The design does not add a dynamic global setting, a channel override, or another price-inheritance layer. Image Generation uses exact returned model/output evidence when available; when evidence is absent or `auto`, settlement chooses the conservative highest valid single-call price constrained by the actual image model and output, and records a billing diagnostic.

Web Search charges completed `search` actions but not `open_page` or `find_in_page`. A completed action whose type is absent or unknown is conservatively charged as one search of the same requested specification and diagnosed, following the accepted preference for a bounded small overcharge over systematic undercharge.
