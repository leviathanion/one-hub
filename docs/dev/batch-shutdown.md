# 批处理优雅停机

沿用 `batch_update_enabled` 开关（默认关闭）和 `batch_update_interval`（开启后默认 5 秒），没有新增配置。禁用时继续直接写日志与统计。

启用时，HTTP 接口停止并等待请求、WebSocket 排空、支付资源关闭完成后，停止批次准入。定时 worker 等待在途刷新并运行最后一次 flush，最后才关闭数据库。重复停止返回相同完成结果；关闭后的日志/统计入队明确拒绝，调用方报告错误。

周期写入每次最多 5 秒。最终落盘使用已有 30 秒 shutdown 总预算的剩余时间；等待或数据库写入超时会返回未完成错误。统计增量写入和日志批次的错误均汇总至 shutdown；日志批次采用一个事务，不对失败或提交结果不确定的增量自动重放，以免重复统计。之前周期刷写失败也保留在停止结果中。

这些日志和统计仍是非权威用量投影，停机流程不修改用户余额结算。数据库不可用时会明确报告无法确认持久化的日志数/统计增量；这不是数据库恢复机制，也不保证断电、SIGKILL 或最终落盘失败后的数据恢复。无需 Schema 迁移；代码回退不会撤销已落盘投影。
